# キャリア部管理ツール

求職者・案件・パートナー・売上・原価・稼働人材を一元管理するブラウザ完結型ツール。

## 🎯 主要機能

### 📋 タブ構成

| タブ | 内容 |
|---|---|
| **求職者** | 4軸ランク評価 / 希望・提案単価 / IS/FS実績 / 経験サービス商材 |
| **案件** | 案件No表示 / 募集人数管理 / 複数人受注対応 / マッチング |
| **稼働人材** | 月単価・原価・粗利・原価率を月別管理 |
| **パートナー** | 親密度・連絡履歴・取扱職種・配信実績（81社登録済み） |
| **ダッシュボード** | 月次の売上/原価/粗利グラフ + 明細テーブル |
| **マッチング** | 案件↔候補者の双方向適合度マッチング |

### 💴 売上・原価管理

- 月別に売上明細を登録（請求書ステータス管理付き）
- 原価を **稼働費 / 交通費 / 紹介料 / インセンティブ** に分けて記録
- 各案件×人材の粗利・原価率を自動計算

## 🚀 使い方

1. **https://kojiromatsuta43-gif.github.io/management-tool/** を開く
2. 初回起動でデータが自動で入る
3. ヘッダー右の「▤ データ」から手動取り込み・バックアップ・CSV書出しが可能

### データ管理について

- データは**ブラウザのlocalStorageに保存**されます（同じブラウザ・同じ端末でのみ保持）
- 機種変更・複数端末で使う場合は「▤ データ」→「⬇ 全データを JSON で書き出す」で書き出して、別端末で読み込み
