# キャリア部管理ツール

求職者・案件・パートナー・売上・原価などを一元管理するためのブラウザ完結型ツール。

## 公開URL

GitHub Pages 有効化後、ここに記載されます。

## 機能（現状）

- 求職者管理（4軸ランク、希望/提案単価、IS/FS実績）
- 案件管理（クライアント単価、求める条件）
- 案件 ↔ 求職者の双方向マッチング
- パートナーマスタ
- PDF出力
- localStorage によるブラウザ内永続化

## 今後の追加予定

- 売上管理（請求書管理含む）
- 原価管理
- 稼働人材管理（単価・原価率・利幅）
- パートナー詳細管理（親密度・連絡履歴）
- KPI ダッシュボード（月次の粗利/売上/原価/原価率）
- 受注見込み・失注見込み管理
